# 台股量化計算資料層需求

## 1. 狀態與目標

需求名稱：**台股量化計算資料層**（Taiwan Quant Dataset）。本文件記錄使用者已確認的修訂。價格依日期順序處理，以使用範圍內每檔股票的第一筆行情建立起始股數尺度，不另外指定基準日；換股生效後只調整當日及後續價格，不回頭修改先前行情。先前實作、測試及驗收依據舊慣例，不能視為本修訂符合性的證據。本修訂設計已經使用者確認，已退出範圍的實作須刪除；實作及本次驗收紀錄見[設計 §9](taiwan-quant-dataset-design.md#9-本次驗收紀錄)。

目標為離線整理已下載的官方行情及公司行動；輸出存取方式與具體格式待使用情境確認。不提供回測引擎。

[專案需求](project-requirements.md)、[現有台股需求](taiwan-equity-data-requirements.md)與[現有台股設計](taiwan-equity-data-design.md)描述既有功能；本修訂不改變其界線，也不把原有觀察股池或候選事件重新標記為已驗證。

## 2. 已確認範圍

- 離線使用既有 TWSE／TPEx 官方行情、事件摘要及必要明細；既有匯入流程已解析來源內容，不混入舊 FinMind 記錄。本修訂不改下載請求、TTL、重試、refresh、原始檔／歷史結果保存政策或既有報告。沿用上市除權息、減資明細及上櫃內嵌明細，不要求額外下載面額變更明細，也不新增付款日期來源。
- 分類目標為上市／上櫃普通股，保留「普通股／非普通股／unknown」分類及必要依據；unknown 指證券類型無法判定，不是市場未知。不能因類型無法判定就當成普通股。
- 行情依來源股票代碼、行情日期整理，保留來源市場欄位；不建立跨日期市場轉換、跨市場同碼整合或公司身分／沿革模型。
- 原始行情與換股調整後 OHLC 並存。價格只因減資及面額變更的換股而調整；現金股利、股票股利／無償配股及每股退還股款不調整價格。換股率 m 定義為換發後股數／原股數。每檔股票從第一筆行情以累積倍率 C=1 開始，依日期順序在換股生效時累乘 m，當日及後續 OHLC 乘 C；先前行情不重算，不另設基準日參數。
- 現金股利、股票股利／無償配股條件及每股退還股款分別記錄，包括減資併案分配。可選現金金額缺值依業務意義為零，不另標記不完整；金額所依據的原股口徑及日期依來源記錄，不推定發款日。
- Python 讀取、匯出及具體輸出格式暫不屬範圍，待使用情境確認。

## 3. Input → Process → Output

```text
INPUT
  既有官方行情、事件摘要／明細與其來源參照
  官方編碼原則及必要商品分類證據
  查詢日期、來源、股票代碼（具體使用介面待定）
       |
       v
PROCESS
  唯讀取得資料；同一查詢重複儲存結果不得重複計數
  -> 普通股／非普通股／unknown 證券類型分類
  -> 保留來源股票代碼、日期、市場及欄位
  -> 依官方來源條件解析公司行動與可用分配資料
  -> 每檔股票按日期升序，從第一筆行情以累積倍率 C=1 開始
  -> 換股生效時更新 C；以當時 C 調整當日及後續 OHLC，不回改先前行情
       |
       v
OUTPUT
  未調整行情、分類及來源參照
  換股調整後 OHLC（原始 OHLC × 當日累積倍率）
  公司行動、現金股利、股票股利／無償配股條件及退還股款分別記錄與來源參照
  存取方式及具體格式待使用情境確認
```

## 4. 功能需求與接受條件

| ID | 需求 | 最低接受條件 |
|---|---|---|
| TQD-01 | 離線使用既有官方行情及公司行動，保留可識別實際使用值的來源參照。 | 不發出請求、不回補、不啟用計時器；來源參照足以指出採用的來源值，不另建 lineage 認證制度。 |
| TQD-02 | 同一查詢重複儲存的結果不得重複計數。 | 依已確認設計使用固定內部輸入選擇規則；不提供使用者版本選擇功能，也不要求版本／manifest 產品功能。 |
| TQD-03 | 保留「普通股／非普通股／unknown」證券類型分類及必要分類依據。 | ETF、TDR、特別股等分類為非普通股；無法判定證券類型者為 unknown，不當成普通股。unknown 不代表市場未知。 |
| TQD-04 | 行情保留來源市場、股票代碼及行情日期。 | 不推導市場轉換、不整合跨市場同碼行情、不串接新舊公司代碼或建立公司身分／沿革模型。 |
| TQD-05 | 保留未調整 OHLC、股數及金額的來源意義。 | 不填補來源沒有的行情；非交易日不補價。現金金額的缺值規則見 TQD-06，不擴用到行情價格或必要換股輸入。 |
| TQD-06 | 依官方來源條件解析公司行動；分別記錄現金股利、股票股利／無償配股條件及退還股款（包括減資併案分配）與來源參照。 | 可選現金股利與退還股款金額缺值時為零，不另標記不完整。分配金額的原股口徑及日期依來源記錄，不推定付款／入帳日；不把現金從價格因子扣除。缺值為零不擴用到配股率、必要換股率或價格輸入，也不適用於解析錯誤。 |
| TQD-07 | 以第一筆行情建立起始股數尺度，不另設基準日；按日期升序，換股生效後只調整當日及後續價格。減資事件倍率取直接換股率 m=換發後股數／原股數；面額變更取直接 m，或摘要事件前價格 P／恢復買賣參考價 Q。 | 初始 C=1；每次事件生效先更新 C=C×事件倍率，再計算當日 OHLC×C。四個 OHLC 使用相同 C，同一事件僅累乘一次，成交量與金額不變。不使用未來事件，不回改先前行情，不追溯首筆行情已反映的換股。現金股利、股票股利／無償配股及退還股款不改變 C。倍率來源及數值要求見 §4.1。 |
| TQD-08 | 按已確認的官方來源契約解析、計算；無法處理時明確報錯。 | 成功的空事件回應不產生事件列。必要輸入缺少或無法解析／計算、來源回應錯誤、格式變更時，指出問題並失敗，以便修正解析器，不猜值或當成零。不因併案、現金增資或員工增資等名稱就阻擋換股計算；按來源提供的換股條件使用，不擴充未要求的事件模型。 |
| TQD-09 | 原始 OHLC 與同因子調整後 OHLC 分開保留；數值結果保留實際使用值的來源參照。 | 不宣稱調整價為當時成交價、含息報酬或股利再投資；不代算持股、現金帳務或付款日。 |
| TQD-10 | **暫移出範圍：**Python 讀取、匯出及具體輸出存取能力。 | 待使用情境確認後再定，不在本修訂承諾介面或格式。 |

| TQD-12 | 金融運算使用明確的精度與捨入規則。 | 不依賴二進浮點運算；具體精度依已確認設計，不將來源參考價捨入當成普遍價格政策。 |
| TQD-13 | 不修改來源資料或既有報告語意。 | 不 migration／relabel production，不下載、不回補、不啟用排程、不刪除 raw／evidence；唯讀來源，不忽略 SQLite WAL。 |

### 4.1 起始尺度與順序調整算法

- 每檔股票獨立處理，以使用範圍內第一筆行情日期 d0 為起點；第一筆累積倍率為 1，價格不變。不是把第一個價格正規化為 1 或 100，也不另外輸入基準日。
- 行情與換股事件按日期先後處理，不以 API 回傳順序或下載時間決定先後。事件以來源提供的換股生效／恢復交易日套用，不以公告或下載日套用。
- 減資：每千股換發 N 股時，事件倍率為 m=N/1000；來源直接提供等價換股率時按其定義使用。不從含股利、退還股款效果的價格比反推減資換股率。
- 面額變更：直接提供 m 時，事件倍率為 m；採摘要價格時，事件倍率為 P/Q，其中 P 是事件前價格，Q 是恢復買賣參考價。保留採用值的來源；價格可能經捨入，P/Q 不宣稱為精確換股率。
- 對行情日期 d，只累計 d0 < 事件生效日 <= d 的換股事件，各一次。事件生效日有行情時，先更新倍率再計算該日價格；當日無行情時不補價，更新後的倍率供後續行情使用。
- 現金股利、股票股利／無償配股、退還股款只記錄，不更新累積倍率。必要倍率或價格無法使用時依 TQD-08 報錯，不默認為零或 1。

```text
初始累積倍率 C = 1
換股生效時：C = C × 事件倍率
每筆調整後 OHLC = 該筆原始 OHLC × 當時 C
```

最低驗收例子（只包含換股，不含現金分配）：

| 日期順序 | 原始收盤價 | 當日換股事件 | 累積倍率 C | 調整後收盤價 |
|---|---:|---|---:|---:|
| 第一天 | 100 | 無 | 1 | 100 |
| 第二天 | 102 | 無 | 1 | 102 |
| 第三天 | 51 | 每 1 股換 2 股，倍率 2 | 2 | 102 |
| 第四天 | 53 | 無 | 2 | 106 |
| 第五天 | 106 | 每 1 股換 0.5 股，倍率 0.5 | 1 | 106 |

第三天的事件不得改變第一、二天結果；第五天的事件不得改變前四天結果。加入較晚日期資料或事件，也不得改變先前已計算的價格。首筆行情當日或之前已反映的換股不再累計。

精度與分類判定細節依已確認的[設計](taiwan-quant-dataset-design.md)；輸出存取方式及格式仍待使用情境確認。不需要但已實作的功能須刪除，不只停用。

## 5. 分類規則依據及界線

官方來源：[《中華民國證券市場編碼原則》PDF](https://www.twse.com.tw/staticFiles/marketAnnounce/marketAnnounce/1090511-10900075091-3.pdf)，2020-05-01 金管證券發字第1090340666號函核定。

- 第 1 頁壹、二至四：四位數字股票代碼及上市／上櫃／興櫃沿用代碼。此編碼原則不構成本資料層的跨市場整合或公司身分建模要求。
- 第 1 頁壹、八：特別股加 A–W 字母。
- 第 5 頁壹、二十四、二十五：外國企業股票採同樣四碼原則，其他證券另依相應編碼。
- 文件不是「任何四碼都是普通股」的證明。本機 2026-10-22 官方 ISIN 快照交叉檢查有四碼 ETF 及四碼 TDR；排除 00 開頭仍會留下 TDR。
- 不將今日分類／名冊成員資格宣稱為每個歷史日期的法律證明，不以名稱或代碼外觀覆蓋矛盾官方分類；保留證券類型未知，且不把它當作未知市場。分類證據不是完整歷史證券身分認證。
- 本需求不要求完整歷史主檔，也不承諾完整市場母集合、沒有生存者偏誤或任何永久代碼不重用保證。

## 6. 可行性驗證摘要（設計背景，非交付驗收）

下列先前本機唯讀資料及獨立暫存 POC 僅是設計背景，不作產品驗收證據。舊版設計曾記錄的測試映射及 bounded production 結果，均不能證明本修訂行為；本修訂已另行核准設計，新的實作與驗收結果見[設計 §9](taiwan-quant-dataset-design.md#9-本次驗收紀錄)。

1. 官方 ISIN 快照可解析商品分組、代碼、ISIN、CFI、掛牌日與市場；存在非 TW 前綴的 ISIN，不得因而排除外國企業普通股。
2. **舊慣例 POC 僅為歷史背景（不適用本修訂，非驗收證據）：**舊事件樣本、數值、日期邊界及阻擋檢查均不能證明本修訂行為或要求。
3. 本需求採用明示的順序換股算法；不將來源參考價的捨入視為通用價格政策，也不宣稱是交易所官方還原價。

## 7. 非目標及授權邊界

不交付回測引擎、策略、成交模擬、交易成本／滑價、持倉現金帳務、股利入帳／再投資、總報酬、永久證券 ID、完整法律身分鏈、完整交易日曆、PIT 或自動抓取新分類來源。亦不要求歷史退市支援、當前名冊過濾／保護、跨日期市場轉換或跨市場整合、缺漏／衝突／未驗證區間報告、覆蓋完整性認證、隔離／阻擋區間系統、品質 manifest、Python 讀取 API、匯出、版本管理或指定輸出格式。消費端負責持股及實際現金帳務；本層不推定付款日。

來源匯入由既有流程提供，本資料層維持離線，不發出下載請求、不回補、不啟用計時器；既有下載器設定、來源資料及報告不變。本文件不授權 production 清理、全量轉換、回補或外部 evidence 修改。
